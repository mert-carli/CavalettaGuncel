# CAVALETTA — Collection 2026

> **Doğal dokular. Zamansız yaşam alanları.**  
> *Handcrafted for everyday living.*

Cavaletta resmi kurumsal web sitesi ve 2026 dijital katalog deneyimi. Akdeniz zanaatı, %100 yapıştırıcısız el dikişi ve geri dönüştürülmüş kordon dokularıyla şekillenen 21 parçalık imza seçki.

- **Canlı Demo (GitHub Pages):** [https://mert-carli.github.io/CavalettaGuncel/](https://mert-carli.github.io/CavalettaGuncel/)

---

## ✨ Öne Çıkan Özellikler

- **21 İmzalı Tasarım**: Tavola (Masa), Ordine (Düzen), Casa (Yaşam) ve Sereno (Banyo & Spa) serileri.
- **34 Sayfalık İnteraktif Katalog Okuyucu**: Orijinal PDF ve çift modlu flipbook deneyimi, zoom ve bölüm yer imleri (bookmarks).
- **Canlı Arama & Akıllı Filtreleme**: Türkçe karakter duyarsız anlık model, ebat ve koleksiyon araması.
- **Ticari Dönüşüm Kanalları**:
  - Ürün detay modalından tek tıkla WhatsApp sipariş ve bilgi bağlantısı.
  - Model bilgileriyle otomatik dolan B2B & mimari teklif talep formu.
  - Floating WhatsApp concierge ve yukarı dön (Back to top) erişimi.
- **The Beauty of Texture**: İnteraktif dokunma ve malzeme sekmeleriyle dinamik makro görsel sunumu.
- **%100 Responsive & Mobil Uyumlu**: Akıllı telefon, tablet ve geniş masaüstü ekranlar için optimize edilmiş mizanpaj.
- **Sıfır Dış Bağımlılık (Zero Dependencies)**: Modern Vanilla JavaScript, saf CSS3 Design System ve optimize WebP varlıklar.

## 🚀 Çalıştırma

Projeyi yerel ortamınızda görüntülemek için:

1. Depoyu klonlayın:
   ```bash
   git clone https://github.com/mert-carli/CavalettaGuncel.git
   cd CavalettaGuncel
   ```
2. Klasöre girip `index.html` dosyasını herhangi bir modern tarayıcıda açın veya yerel sunucu başlatın:
   ```bash
   python -m http.server 8000
   ```
   Tarayıcınızda `http://localhost:8000` adresine gidin.
